# Diplom_work
Diplom Work - l Line Personnel management system
Проект от компании «ILine»: система управления персоналом

Инструкция по запуску:
- Установите все необходимые библиотеки согласно requirements.txt
- Запустите app.py
- Сервер запустится локально http://127.0.0.1:5000

Функционал проекта:

1 Создана модель Flask-SQLAlchemy, отображающая структуру таблиц из базы данных, 
созданной в рамках проекта «Онлайн-каталог сотрудников». Модели включает все необходимые 
поля и связи между таблицами (например, связь «начальник-подчиненный»). 
Связь между моделями реализуется через внешние ключи.

2 Разработана страница, отображающая список всех сотрудников. Каждый сотрудник представлен с 
полной информацией (ФИО, должность, дата приема на работу, зарплата, начальник).

3 Реализована сортировка по имени, заработной плате (по возрастанию/по убыванию) и дате приема (от возрастанию/по увбыванию),
используя параметры GET-запроса.

4 Реализован функционал поиска сотрудников по ФИО (полное или частичное совпадение).
Результаты поиска отображаются на той же странице.

5 Реализована возможность изменения начальника сотрудника путем прямого обновления записи в базе данных.

6 Реализована функция добавления сотрудника с отображением полей для ввода данных о новом работнике.

7 Реализована функция удаления сотрудника из базы данных по ID

8 Реализован функционал вывода списка подчиненных у конкретного руководителя
